# Changelog

## v2.0.0-rc2 — 2026-10-07 — В ПРОЦЕССЕ ТЕСТИРОВАНИЯ

- Основа: v2.0.0-rc1; логика mute, AA91-синхронизации, GPIO и Coolix TX не менялась.
- При любом входе в `HEAT` стартовая температура устанавливается в **30°C**.
- При любом входе в `COOL` стартовая температура устанавливается в **25°C**.
- Работает также для `OFF → HEAT/COOL`; после входа температуру можно менять свободно.
- `FAN_ONLY` температуру не меняет.
- **v1.5 остаётся stable; v2.0.0-rc2 пока только тестируется.**

## v2.0.0-rc1 — 2026-10-07 — PRE-STABLE

- v1.5 остаётся текущей стабильной версией; RC публикуется отдельным YAML и пока не заменяет stable.
- Сохранено штатное ESPHome Coolix-управление через GPIO6/MOSFET.
- Persistent mute больше не зависит от запаздывающего `confirmed_mode`: после HA OFF → ON прошивка ждёт реально принятую DISPLAY команду и только затем восстанавливает `B5F5A5`.
- Полные `AA 91 0D` от штатного пульта используются для синхронизации режима/вентилятора/температуры/выключения с Home Assistant.
- На тестируемой второй сборке принятый DISPLAY → MAIN поток подтверждён на GPIO20; GPIO4 несёт MAIN → DISPLAY `55...`.
- Компактные `AA 91 07` собственного TX используются как ACK и не конкурируют с HA за climate state.
- Старый `55 90/91` state parser убран из роли authoritative climate source, что исключило откаты режима/скорости и существенно уменьшило код.
- Не включены retry OFF, triple-send, DIRECT-CONTROL/FIX2/FIX3 и прямой BUS-TX.
- Тест: холодный старт, mute, пульт → HA, HA → сплит и обычные ON/OFF работают. Один редкий пропуск ON наблюдался при стресс-переключениях; причина остаётся под наблюдением и не маскируется повторной отправкой.
- Полная история решений: `docs/V2_RC1_NOTES.md`.

## v1.5 — 2026-09-15

- Исправлено сохранение состояния `Без звука` после перезапуска Home Assistant и переподключения ESPHome API.
- Для template-switch добавлен `restore_mode: DISABLED`.
- `mute_desired` повторно публикуется после загрузки ESP и подключения API-клиента без отправки `B5F5A5`.
- Логика режимов, вентилятора, температуры и декодирования из v1.4 не изменялась.
- Проверено 15.09.2026: при `Без звука = ON` обычный «Перезапуск Home Assistant» сохраняет состояние ON.
- Добавлена отдельная инструкция по диагностике OTA-отката и проблем питания.

## v1.4

- Стабильная климатическая логика на базе физически проверенной v1.2.
- AUTO / HEAT_COOL оставлен включённым.
- Скорость вентилятора запоминается между режимами.
- Добавлено постоянное пользовательское состояние `Без звука` с однократным повторным применением после настоящего OFF → ON.
